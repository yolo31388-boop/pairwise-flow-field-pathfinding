# pairwise-flow-field-pathfinding

一百个怪挤在门口，流场只算了一个出口，门口形成一条细线，后面的怪互相推挤；流场积分用 8 邻域但代价没算对角，怪走成锯齿路径；动态障碍放下来后流场整张重算，每帧卡 20 毫秒；传送门两侧的代价没连起来，怪绕远路；坡度代价按高度差线性算，陡坡被当成平地的两倍，怪宁愿走悬崖；群体分离只对最近邻居生效，密集时抖动；个体半径没进流场，瘦怪能过缝胖怪卡住；流场更新按固定帧轮转，障碍移动后路径指示旧方向；目标移动后只改了目标格，周围积分没重算，路径不收敛；多层级流场在层级边界处方向突变，怪在边界来回横跳。gameplay/flow_field_pathfinding.py 是核心，tests/test_flow_field_pathfinding.py 15个红。要修的是：多出口汇聚；对角代价；增量更新；传送门连通；坡度按可通行性；密度分离；按半径膨胀障碍；障碍变更立即更新；目标变更局部重算；层级边界插值。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
